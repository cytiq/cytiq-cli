## Согласованные решения

- Два новых крейта: `cytiq-population` и `cytiq-specimen`.
- Источник онтологии и knowledge schemas — внешний `cytiq-tree`, без второго
  генератора онтологии в engine.
- EventAnnotations — адаптеры существующих membership/predictions Parquet и
  versioned descriptor; новый единый event-level Parquet не вводится.
- P1 охватывает conventional gating/classify, spectral gating и существующий
  CyTOF classify. Изменения Prefect/API/Tree вне этой задачи.
- Стратегии: `independent`, `prefer_reference`, экспериментальная `reference_ratio`.
- Повторные acquisition сохраняются, активная выбирается явно; `qc_best` нет.
- Коды 0–4 и JSON outcome относятся к новым командам. Старые команды сохраняют
  прежнее поведение.
- Готовность P1 — research/shadow-ready. Реальный исторический shadow-run,
  клиническая валидация, legacy reconciliation, абсолютные концентрации,
  FlowSOM annotation и новый CyTOF preprocessing не входят в этот этап.

## Реализация

### cytiq-population

Основной код: `crates/cytiq-population/src/`.

- Контракты v1: `EventAnnotations`, `PopulationObservation`; типизированная цель
  `population` / Boolean `phenotype` / scoped `residual`.
- Exact `u64` observed counts и отдельные `f64` estimates/fractions; explicit
  measured/estimated/not_measured/qc_rejected/below_detection/not_applicable.
- Явные denominators, методы, lineage, supporting counts и identities строк.
- Streaming native Parquet adapters: membership schema v2, classify bundle v2–v4.
  Membership остаётся multilabel; unknown/abstain не становится популяцией.
- Проверки acquisition, исходных event IDs, покрытия eligible events, одного
  общего final combined mask для producer и QC.
- QC обязан ссылаться на manifest, зафиксированный specimen plan.
- Classifier source дополнительно фиксирует `bundle_manifest` и `abstain_margin`;
  совпадения только ONNX hash недостаточно.
- Knowledge artifacts v2 проверяются по pinned upstream schemas, defaults,
  hierarchy, signatures, projections и SHA-связям. Каноническая сериализация
  выделена из classify; legacy bundle digest semantics сохранены.
- Пакетная запись и проверка completion/outcome, long summary Parquet.
- Лимиты: документы 16 MiB / 64 уровня / 1 млн expanded values; batches 65 536;
  raw lineage — bitmap, до 1 млрд events; до 1 млн summary observations.

Источник schemas: `cytiq/cytiq-tree@6979697dd898387a841571edb78969ce737c8076`.
Файлы и hashes перечислены в `crates/cytiq-population/contracts/cytiq-tree.lock.json`.

### cytiq-specimen

Основной код: `crates/cytiq-specimen/src/`.

- `SpecimenLayout`, immutable acquisition selection в `SpecimenPlan`,
  `SpecimenResult` с исходными и отдельными согласованными результатами.
- `specimen run` читает summary packages, не FCS и не native event annotations.
- Нет автоматического сложения детей дерева, усреднения панелей и fallback
  reference panel.
- `reference_ratio = source_population × reference_anchor / source_anchor`;
  anchors должны быть положительными, measured и совместимыми.
- Технический QC, completeness и biological consistency разделены. Biological
  disagreement не удаляет и не переписывает измерения.
- `SpecimenResult::load` проверяет package, версии, row identities, source
  references, QC/outcome и JSON/Parquet agreement.

### Изменения существующих крейтов

- Manifest: отсутствующая версия — v1; v2 допускает повторные acquisition и
  `cytometry: cytof`. Для CyTOF запрещена fluorescence compensation.
- Preflight: CyTOF не получает fluorescence spillover / spectral controls.
- Provenance остаётся RunRecord v2; добавлены staged record preparation и outcome v1.
- QC `CheckStatus` дополнен Deserialize без изменения JSON формата.
- CLI thin dispatch в `commands/population.rs` и `commands/specimen.rs`.

Новые команды:

```text
cytiq specimen validate
cytiq specimen plan
cytiq population validate
cytiq population observe
cytiq specimen run
```

`--output` новых записывающих команд — директория package. План находится в
`plan/plan.json`. Полный CLI, примеры layouts, состояния, exit codes и правила
публикации: [cytiq-specimen README](../../crates/cytiq-specimen/README.md).

## Docker: важные детали окружения

Пользователь перезапустил Docker во время работы. После этого daemon заработал;
доступ из sandbox потребовал разрешённого escalated запуска.

Обычный `just docker-build` не прошёл из-за TLS interception локального HTTPS
прокси: сначала crates.io, затем отдельный downloader ONNX Runtime с UnknownIssuer.
**Не считать обычную команду успешной без этой оговорки.** TLS verification не
отключалась; Dockerfile и TLS/dependency features репозитория не менялись.

Для локальной проверки создан временный Dockerfile вне репозитория:

- добавлены публичные CA из уже доверенных host bundles;
- использован штатный cache layout `ort-sys` с официальным Linux ARM64 архивом;
- архив скачан по HTTPS и перед распаковкой проверен по SHA-256 из pinned
  `ort-sys 2.0.0-rc.15/build/download/dist.tsv`:
  `380c1b63eedf5671e7b39e4aa0f6c377ecc351c3a7b01ae708a707e73fb54709`.

Образ `cytiq:dev` успешно собран из текущих исходников. В контейнерах с
`--network none`, readonly fixtures и writable временной директорией проверены:
help, specimen plan, compensate, mask combine, qc, gate, population observe,
specimen run и ONNX classify. Независимо проверены result digests, measured zero
и успешный inference.
