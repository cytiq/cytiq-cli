# Synthetic CyTOF classify fixtures

192 generated events, seed 42; no experimental data. Generated by
`cytiq-ml/scripts/generate_classify_fixture.py --cytof` using its locked boosting
extra. `input.fcs` holds raw ion counts for the `cytiq-cytof-arcsinh-v1` recipe
(cofactor 5); `spill.fcs` declares a spillover matrix the recipe must reject.
Contains expected Python features and probabilities and LightGBM/XGBoost v4 bundles.
