# CytoNorm numerical references

`numeric.json` is generated by `parity/cytonorm_numeric.R` with R 4.5.3.
It covers type-7 quantiles, monotone Hermite interpolation with ties, flat
segments, negative values and extrapolation, plus consensus clustering with
fixed codebook and identical resampling schedules.

These are independent R reference outputs, not Rust-generated expectations.
Regenerate with `just parity-cytonorm-fixture` only when the generator or R pin
changes. Workflow tests generate their small FCS cohorts at runtime.
