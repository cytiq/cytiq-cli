# Token-efficient coding

1. Search before reading files.
2. Prefer rg for exact identifiers.
3. Prefer Serena for symbol-level navigation.
4. Use grepai for semantic discovery.
5. Read only relevant functions and nearby code.
6. Avoid dumping entire files and directories.
7. Reuse previously established findings.
8. Run targeted tests before full test suites.
9. Limit tool output to relevant results.
10. Return concise summaries and actionable diffs.
